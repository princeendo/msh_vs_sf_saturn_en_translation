# EXP-0033: Ryu's Official-English Win Quotes From a Rebuilt Image

Task: TR-001
Status: DONE
Confidence: CONFIRMED

## Observation

- `GATE-TRANSLATION` passed (user GO, 2026-10-24).
- Saturn record `k` pairs with arcade English entry `k & 7` (`EXP-0031`).
- The caption pipeline (`RE-022`, `RE-024`) displayed all 16 compiled marker
  records live.
- The compiler's character set lacked `.` and `,`, which Ryu's English uses.

## Hypothesis

Compiling the 16 records from the paired official English, with `.` → `0x08AB`
and `,` → `0x08AC`, gives an image whose every forced record displays its paired
English line legibly.

## Controlled Change

There is one new input: the generated spec (official English instead of markers).
The supporting code changes are two punctuation mappings and a schema pattern.

## Prediction

For each forced index `i` (0-15) after one KO:

- the pointer is `0x002091AC + 76·i`;
- the cart-RAM font equals the compiled font entry, the WRAM-L table equals the
  compiled table, and the display buffer holds record `i`'s codes
  (`verify_records.py`);
- the screen shows arcade entry `i & 7` with the arcade's line break, centred,
  with legible `.` and `,`.

Record 0 has no partner-name placeholder: the spec omits `{P}`, so no name
appears.

**Refuted if:** any record shows other text, blank or garbage cells, illegible
punctuation, or a RAM mismatch.

## Offline Result (2026-10-24)

- **Capacity:** 336 pair cells and 95 distinct pairs against 248 free codes;
  3,669 pair bytes against 30,235 reclaimable. It fits.
- **Compiler checks:** all true.
  - Font: header unchanged, pairs equal composed, sacrificed codes empty, pair
    codes were empty.
  - `MEMFIX` is unchanged outside entry 4.
  - `MC09.PAC`: same decoded length and file size; only target cells changed (910
    decoded bytes).
- **Offline render** (`build/tr001/records-MC09.png`): every record reads as its
  paired entry, centred, with legible punctuation. Records 8-15 repeat 0-7.

## Procedure (live)

1. Launch the patched Mednafen (`fe0edb99…`) on `build/tr001/image_a` with the
   agent enabled.
2. Run `ko_capture.py --checkpoint`. The user plays arcade mode as Ryu (first) and
   Ken, and KOs the first opponent with Ryu.
3. For i in 0-15: `ko_capture.py --state postko.mc --force-index i --setter-pcs
   060AF282`.
4. Run `verify_records.py --compile-dir build/tr001` on all runs, then check every
   screenshot.

## Actual Result (live, 2026-10-24)

- **Checkpoint.** The user played one Ryu KO (Ryu and Ken vs the first team) on
  `image_a` with the patched Mednafen (`fe0edb99…`).
  - `ko_capture.py --checkpoint` saved `postko.mc` (SHA-256 `ab62dec0…5dee`).
  - The natural pick was record 6 (pointer `0x00209374`, frame 8475).
- **Forced runs.** All 16 records were forced from that checkpoint
  (`--force-index i --setter-pcs 060AF282`).
- **Verification.** `verify_records.py --compile-dir build/tr001` reports **16 of
  16 OK** (report SHA-256 `8a60cec3…38b9`, ignored `local/tr001/verify.json`). For
  every record:
  - the pointer equals `0x002091AC + 76·i`;
  - the cart-RAM font equals the compiled entry;
  - the WRAM-L table equals the compiled table;
  - the display buffer holds the record's codes.
- **Screen match.** IoU is 1.0 for every record. Records 8-15 match records 0-7
  exactly, because their codes are identical by policy.
  - The verifier's screen check now accepts a best match whose codes equal the
    forced record's, and reports it as `screen_tie_with_identical_record`.
  - Records 0 and 8 produced byte-identical screenshots (SHA-256
    `48f3c304…69e8`).
- **Visual check.** All 16 screenshots were read: each shows its paired arcade
  entry with the arcade line break, centred, with legible `.` and `,`. Record 0
  shows no partner name.
- **Extra entry.** Each display buffer has one extra `0x0020` entry. The same
  extra 39th entry appeared in every `EXP-0026` marker run, so this is existing
  behavior, not a new effect.
- **Pair glyph cost.** Pair glyphs cost 3,669 bytes; 38 kanji with no use in
  record-shaped text were emptied, freeing 3,756 bytes (compile manifest).

## Conclusion

**CONFIRMED.** A deterministic image rebuilt from the untouched source displays
Ryu's 16 win quotes in official arcade English (record `k` = entry `k & 7`), and
every record is verified in RAM and on screen.

## Uncertainty and Alternatives

- Natural selection was observed once (record 6). The other records were forced,
  as in `RE-024`.
- Only the Ryu-first team context was tested live. `RE-025` showed table bases
  move with team slot, but the content is the same file.
- Emptied kanji: the census found them in no record-shaped text. Text elsewhere
  (endings, menus) was not tested and could need them.
- Pitfall: a frontend frame-advance pause during capture left the debugger halted.
  `loadstate` is refused while halted, so send the agent `run` first.
