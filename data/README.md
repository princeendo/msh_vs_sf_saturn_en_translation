# Data Directory

Store small, structured, factual research data that is safe to distribute. Data must
identify its schema, provenance, generating command or experiment, source hashes, and
confidence.

Allowed tracked content includes derived metadata, reviewed translation records,
addresses and offsets established by evidence, hashes, schemas, and small synthetic
fixtures. Do not track disc images, BIOS files, extracted game content, memory dumps,
save states, screenshots, traces, emulator binaries, or substantial copyrighted text.

Keep raw binary evidence in ignored local paths and refer to it by filename, byte
size, SHA-256, description, and experiment identifier.
