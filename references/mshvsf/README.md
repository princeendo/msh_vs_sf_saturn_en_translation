# MSHvSF References

Use `arcade_us/`, `saturn_jp/`, and `ps1_us/` as logical provenance categories for
permitted notes and metadata. Keep all game images, captures, and extracted contents
outside version control.

`docs/references.md` catalogs the candidate official releases and evidence hierarchy.
Do not merge release identities: MAME's original US arcade sets `mshvsfu` (`970827`)
and `mshvsfu1` (`970625`), Capcom's modern `USA 970707` reissue, US PlayStation
`SLUS-00793`, and the Japanese Saturn target are distinct evidence sources.
