# Documentation References

Store concise citation records and task-oriented summaries here. Do not commit
unauthorized manuals or bulk PDFs. Every summary must link claims to an authoritative
source recorded in `docs/references.md`.

The initial Sega Saturn architecture corpus is cataloged in `docs/references.md`.
Official Sega PDFs were inspected from third-party mirrors but remain external; only
their metadata, hashes, relevant sections, supported claims, and limitations are
tracked.

The SH-2 corpus is also cataloged in `docs/references.md`. It is limited to
processor and SH7604 hardware semantics needed to interpret later debugger evidence;
it does not supply target addresses or game-specific structures.
