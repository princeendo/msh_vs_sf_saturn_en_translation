# Reference Materials

Use this directory for tracked provenance records, bibliographic notes, and links.
Do not store copyrighted game images, BIOS files, manuals, extracted game contents,
screenshots, save states, memory dumps, or emulator binaries here.

For each local reference artifact, track only permitted metadata: descriptive title,
release or revision, filename, byte size, SHA-256, source URL or acquisition record,
retrieval date, license when applicable, and research purpose. Keep the artifact in
an ignored local location.

Reference releases are evidence and translation oracles, not templates. Any claimed
correspondence or shared technical behavior requires its own experiment.
